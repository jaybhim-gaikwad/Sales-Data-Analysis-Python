# Sales Data Analysis Using Python

## Project Overview
This is a beginner-level Data Analysis project built using Python. The project analyzes sample sales data to identify product performance, city-wise revenue, and monthly sales trends.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset Information
The sample dataset contains 5 records with the following columns:
- Product
- City
- Quantity
- Price
- Revenue
- Date
- Month

## Analysis Performed
- Data exploration and summary statistics
- Revenue calculation
- Product-wise sales analysis
- City-wise sales analysis
- Monthly revenue analysis
- Correlation analysis
- Correlation heatmap visualization
- Missing values and duplicate checks

## Key Findings
- Total Revenue: ₹235,600
- Total Quantity Sold: 26
- Best Selling Product: Laptop
- Best Performing City: Pune
- Best Sales Month: January 2026

## How to Run This Project
1. Download or clone this repository.
2. Install the required libraries:
   `pip install pandas numpy matplotlib seaborn`
3. Open Jupyter Notebook.
4. Open `Sales_Data_Analysis.ipynb`.
5. Run the notebook cells.
